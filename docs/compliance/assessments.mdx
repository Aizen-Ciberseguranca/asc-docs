# Assessments

A área **Assessments** concentra as avaliações de compliance realizadas para a organização.

Cada assessment utiliza um framework habilitado e reúne as atividades necessárias para avaliar controles, evidências, GAPs e outros requisitos aplicáveis.

## Acessar os Assessments

Para acessar:

1. Selecione o projeto desejado.
2. Acesse **Compliance → Assessments → Assessments**.

A página possui duas áreas principais:

- **Assessments**
- **Frameworks disponíveis**

## Assessments

A aba **Assessments** apresenta as avaliações já criadas para a organização.

Cada assessment pode apresentar um dos seguintes status:

- **Rascunho**
- **Em andamento**
- **GAP analisado**
- **Relatório gerado**
- **Encerrado**

Esses status permitem acompanhar a evolução da avaliação ao longo do processo de compliance.

## Abrir um assessment

Para acessar uma avaliação existente:

1. Localize o assessment desejado.
2. Clique em **Abrir**.

Você será direcionado aos detalhes do assessment, onde estarão disponíveis as etapas, documentos, controles, evidências e demais recursos relacionados à avaliação.

## Frameworks disponíveis

A aba **Frameworks disponíveis** apresenta os frameworks habilitados para sua organização.

:::info Frameworks habilitados

O catálogo da plataforma pode conter outros frameworks. Nesta área são apresentados para utilização os frameworks que foram habilitados para sua organização.

:::

## Criar um assessment

Quando seu perfil possuir permissão:

1. Acesse a aba **Frameworks disponíveis**.
2. Localize o framework desejado.
3. Clique em **Criar assessment**.
4. Após a criação, acesse o novo assessment pela aba **Assessments**.

A partir desse momento, o assessment poderá ser utilizado para conduzir o processo de avaliação.

:::note Permissões

A criação e a operação de assessments dependem das permissões atribuídas ao usuário.

Perfis com acesso somente para visualização podem consultar as informações disponíveis, mas não realizar as operações reservadas aos usuários autorizados.

:::

## Nenhum assessment disponível

Caso ainda não exista uma avaliação criada, será apresentada a indicação de que nenhum assessment foi criado.

Para iniciar uma nova avaliação, verifique a aba **Frameworks disponíveis**.

## Nenhum framework disponível

Caso nenhum framework tenha sido habilitado para a organização, não será possível criar um novo assessment.

Nesse caso, a plataforma informará que ainda não existem frameworks habilitados para o cliente.

## Fluxo geral

De forma geral, o processo ocorre da seguinte maneira:

1. Um framework é habilitado para a organização.
2. Um usuário autorizado cria o assessment.
3. O assessment é aberto.
4. São coletados documentos e evidências.
5. Os controles são avaliados.
6. GAPs e demais análises são realizados.
7. Os resultados são consolidados em relatórios.

As etapas e funcionalidades disponíveis dentro do assessment podem variar conforme o framework utilizado.
