# Painel de Clientes

O **Painel de Clientes** apresenta uma visão consolidada da evolução do projeto de compliance.

A página permite acompanhar as etapas do trabalho, o plano de ação e indicadores relacionados à maturidade da organização.

## Acessar o Painel de Clientes

Para acessar:

1. Selecione o projeto desejado.
2. Acesse **Compliance → Painel de Clientes**.

O painel será apresentado no contexto da organização associada ao projeto.

## Selecionar o framework

O seletor **Framework** permite definir qual framework será utilizado para apresentação das informações do painel.

Utilize esse recurso quando houver mais de um framework disponível para a organização.

## Visões disponíveis

O Painel de Clientes possui recursos para acompanhar o projeto sob diferentes perspectivas.

Entre as opções disponíveis estão:

- **Painel**
- **Visão da semana**

## Projeto

A visão **Projeto** permite acompanhar a evolução das diferentes etapas do trabalho de compliance.

São apresentadas as fases do projeto, desde o planejamento inicial até a etapa de relatórios.

Também são disponibilizadas informações relacionadas a:

- fases do projeto;
- plano de ação;
- status do intake.

Essa visão permite identificar rapidamente o estágio atual do trabalho.

## Gestão

A visão **Gestão** concentra indicadores para acompanhamento da maturidade e da evolução do projeto.

Entre as informações apresentadas estão:

### Radar por domínio

Apresenta uma visão comparativa da situação dos diferentes domínios avaliados.

### Visão da semana — C-Level

Fornece uma perspectiva executiva das informações relevantes para o acompanhamento do projeto durante o período.

### Visão por domínio

Permite analisar os resultados de acordo com os domínios do framework utilizado.

### Maturidade por domínio

Apresenta o nível de maturidade identificado para cada domínio.

Os níveis são representados de **L1 a L5**.

## Visão da semana

A **Visão da semana** permite acompanhar informações registradas ao longo das fases do projeto.

É possível alternar entre:

- **3 Semanas**
- **Todas as fases**

As informações são organizadas por fase, permitindo acompanhar as anotações e a evolução do trabalho ao longo do projeto.

## Permissões

O Painel de Clientes é uma área de acompanhamento e consulta.

As informações apresentadas dependem da organização, do framework selecionado e dos dados existentes no projeto de compliance.
