# Catálogo de frameworks

O **Catálogo de frameworks** permite consultar os frameworks de compliance disponíveis no ASC.

Essa área funciona como uma referência para conhecer os padrões, regulamentações e modelos de avaliação suportados pela plataforma.

## Acessar o catálogo

Para acessar:

1. Selecione o projeto desejado.
2. Acesse **Compliance → Catálogo de frameworks**.

A plataforma apresentará os frameworks disponíveis no catálogo.

## Organização do catálogo

Os frameworks são organizados por categorias para facilitar a localização e a consulta.

Cada framework possui informações que permitem identificar sua finalidade e o contexto em que pode ser utilizado.

## Consultar um framework

Utilize o catálogo para conhecer os frameworks suportados pelo ASC e identificar aqueles que podem ser aplicáveis à sua organização.

A disponibilidade de um framework no catálogo não significa necessariamente que ele esteja habilitado para utilização no seu projeto.

:::info Catálogo x Frameworks disponíveis

O **Catálogo de frameworks** apresenta os frameworks suportados pela plataforma.

Já em **Assessments → Frameworks disponíveis** são apresentados os frameworks habilitados para utilização pela sua organização.

:::

## Utilizar um framework em um assessment

Para utilizar um framework em uma avaliação:

1. Acesse **Compliance → Assessments**.
2. Selecione **Frameworks disponíveis**.
3. Localize o framework habilitado.
4. Clique em **Criar assessment**.

Após a criação, o assessment ficará disponível para condução da avaliação.

## Recursos específicos

Os recursos disponíveis dentro de um assessment podem variar de acordo com o framework selecionado.

Além das funcionalidades comuns de avaliação, alguns frameworks podem disponibilizar recursos específicos, como:

- gestão de riscos;
- declaração de aplicabilidade (SOA);
- relatório final;
- análise de Risk Score;
- recursos de inteligência;
- funcionalidades específicas relacionadas ao escopo do framework.

Consulte **Detalhes do assessment** para conhecer as funcionalidades que podem estar disponíveis durante uma avaliação.

## Permissões

A consulta ao catálogo e a utilização dos frameworks dependem das permissões e configurações atribuídas à organização.

A criação de assessments também depende do nível de acesso do usuário.
