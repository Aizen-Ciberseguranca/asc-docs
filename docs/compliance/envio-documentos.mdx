# Envio de documentos

Durante um assessment de compliance, você pode receber um **link para envio de documentos**.

Esse link permite acessar uma página específica para fornecer os documentos solicitados durante a avaliação.

## Acessar a solicitação

Ao receber o link:

1. Abra o endereço fornecido pelo responsável pelo assessment.
2. Acesse a página **Envio de Documentos**.
3. Consulte os documentos solicitados.
4. Forneça as informações disponíveis para cada item.

:::info Link de acesso

O link é gerado pelo responsável pelo assessment e pode possuir um período de validade.

Caso o link esteja expirado ou tenha sido revogado, solicite um novo link ao responsável pela avaliação.

:::

## Enviar um documento

Quando possuir o documento solicitado:

1. Localize o item correspondente.
2. Selecione a opção para anexar o arquivo.
3. Escolha o documento.
4. Confirme o envio conforme as opções apresentadas na página.

Certifique-se de enviar o documento correspondente ao item solicitado.

## Não possuo este documento

Caso sua organização não possua um dos documentos solicitados, utilize a opção:

**Não possuo este documento**

Essa informação permite que o responsável pela avaliação saiba que o documento solicitado não está disponível.

:::note

Utilize **Não possuo este documento** somente quando o documento realmente não estiver disponível.

:::

## Após o envio

Os documentos enviados ficam associados ao processo de coleta do assessment.

O responsável pela avaliação poderá analisar o material e dar continuidade ao processo de compliance.

Dependendo da análise realizada, um item poderá precisar de informações adicionais ou ser devolvido para revisão.

## Segurança dos documentos

Os documentos enviados podem conter informações internas da organização.

Antes do envio:

- confirme que está utilizando o link correto;
- envie somente os documentos relacionados à solicitação;
- verifique se o arquivo selecionado é o documento correto;
- não compartilhe o link de coleta com pessoas que não participam do processo.

## Problemas com o link

Caso não consiga acessar a página de envio:

- verifique se o link foi copiado integralmente;
- confirme se o período de validade não terminou;
- verifique com o responsável se o link não foi revogado.

Se necessário, solicite a geração de um novo link.

## Para responsáveis pelo assessment

O link de coleta é criado na aba **Intake** do assessment.

O responsável pode:

- gerar um novo link;
- definir sua validade;
- copiar o endereço;
- abrir o link;
- revogar o acesso.

O envio do endereço para o destinatário é realizado pelo próprio responsável pelo assessment.
