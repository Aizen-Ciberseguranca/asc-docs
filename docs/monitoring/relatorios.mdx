# Relatórios

A área **Relatórios** permite consultar e baixar os relatórios de monitoramento disponibilizados pela Aizen para sua organização.

Os relatórios são organizados por período para facilitar o acompanhamento do histórico.

## Consultar relatórios

Acesse **Monitoring → Relatórios**.

A página apresenta os períodos disponíveis e informações como:

- mês e ano;
- quantidade de arquivos;
- data de envio;
- data de download, quando aplicável.

Quando ainda não houver relatórios publicados, será apresentada a mensagem:

**Nenhum relatório publicado ainda.**

## Acessar os relatórios do mês

Para consultar os arquivos de determinado período:

1. Acesse **Monitoring → Relatórios**.
2. Localize o mês desejado.
3. Abra o período.
4. Consulte os arquivos disponíveis.

A página do período apresenta os arquivos publicados e seus respectivos tamanhos.

## Baixar um relatório

Para realizar o download:

1. Abra o período desejado.
2. Localize o arquivo.
3. Clique sobre o relatório.

O download do arquivo será iniciado.

:::info Disponibilidade

Os relatórios apresentados dependem dos arquivos publicados para sua organização. Por isso, a quantidade de períodos e arquivos disponíveis pode variar.

:::

## Períodos sem arquivos

Caso um período esteja disponível, mas não contenha arquivos publicados, o ASC apresentará:

**Nenhum arquivo nesta pasta.**
