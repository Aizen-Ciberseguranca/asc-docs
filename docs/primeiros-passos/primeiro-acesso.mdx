# Primeiro acesso

O acesso ao **Aizen Security Center (ASC)** é realizado por meio do **Aizen SSO**, serviço responsável pela autenticação dos usuários da plataforma.

Não é necessário criar uma conta diretamente no ASC. O usuário deve ser previamente cadastrado pela Aizen ou pelo administrador autorizado da organização.

## 1. Receba suas credenciais

Após a criação da conta, você receberá as informações necessárias para realizar o primeiro acesso.

Uma **senha temporária** é gerada para a nova conta e deverá ser alterada no primeiro login.

## 2. Acesse o ASC

Na página inicial do ASC, clique em:

**Entrar com Aizen SSO**

Você será direcionado para a página de autenticação.

Informe:

- seu e-mail corporativo;
- sua senha temporária.

## 3. Crie uma nova senha

No primeiro acesso, o sistema solicitará a substituição da senha temporária.

Defina uma nova senha e conclua a alteração para continuar.

## 4. Configure o MFA

Dependendo da política de segurança aplicada à sua organização, será necessário configurar a **autenticação multifator (MFA)**.

Quando solicitado, siga as instruções apresentadas pelo Aizen SSO para configurar seu aplicativo autenticador.

Após a configuração, informe o código de verificação gerado pelo aplicativo.

:::info
Quando o MFA for obrigatório, o acesso às funcionalidades da plataforma permanecerá restrito até que sua configuração seja concluída.
:::

## 5. Acesse a plataforma

Após concluir a autenticação, você será direcionado para a **Visão geral** do ASC.

A partir dela, os projetos e módulos disponíveis serão apresentados de acordo com as permissões associadas à sua conta.

:::note
Os módulos, projetos e funcionalidades disponíveis podem variar conforme o perfil do usuário e os serviços habilitados para sua organização.
:::
