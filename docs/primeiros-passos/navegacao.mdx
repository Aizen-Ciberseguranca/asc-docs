# Navegação

Após realizar o login, o usuário é direcionado para a **Visão geral** do Aizen Security Center.

A navegação pela plataforma é realizada principalmente pelo **menu lateral esquerdo**, que permite acessar projetos, módulos e configurações disponíveis para sua conta.

## Estrutura de acesso

O ASC organiza os recursos na seguinte estrutura:

**Cliente → Projeto → Módulo**

### Cliente

O cliente representa a organização à qual os projetos e usuários estão associados.

Usuários de clientes acessam somente o ambiente de sua própria organização.

### Projeto

Um cliente pode possuir um ou mais projetos.

Utilize o **seletor de projeto** no menu lateral para alternar entre os projetos disponíveis para sua conta.

:::note
A lista apresentada depende das permissões associadas ao seu usuário.
:::

### Módulos

Após selecionar um projeto, o menu apresenta os módulos habilitados e liberados para seu usuário.

Os principais módulos da plataforma são:

- **Intelligence**
- **Monitoring**
- **Compliance**

Os itens disponíveis dentro de cada módulo podem variar conforme seu perfil de acesso.

## Menu lateral

O menu lateral concentra a navegação principal da plataforma.

Por meio dele, você pode:

- selecionar o projeto;
- acessar os módulos disponíveis;
- navegar pelas funcionalidades de cada módulo;
- acessar seu perfil;
- acessar configurações disponíveis para sua conta;
- encerrar sua sessão.

O menu pode ser recolhido ou expandido conforme necessário.

## Selecionar um projeto

Para alterar o projeto atual:

1. Localize o seletor de projeto no menu lateral.
2. Clique em **Selecionar projeto** ou no nome do projeto atual.
3. Escolha o projeto desejado.
4. Aguarde o carregamento dos módulos disponíveis.

Se houver apenas um projeto disponível, a plataforma poderá selecioná-lo automaticamente.

## Acessar um módulo

Com um projeto selecionado, os módulos disponíveis serão exibidos no menu.

Clique no módulo desejado para acessar suas funcionalidades.

:::info
Um módulo somente será apresentado quando estiver habilitado para o projeto e liberado para o seu usuário.
:::

## Perfil e configurações

Na parte inferior do menu lateral, clique no seu nome para acessar **Perfil e segurança**.

Nessa área é possível consultar informações da conta e acessar as configurações relacionadas à autenticação.

Também podem existir opções adicionais de configuração conforme seu perfil de acesso.

## Sair da plataforma

Para encerrar sua sessão, utilize a opção **Sair** disponível no menu lateral.

Ao sair, sua sessão no ASC é encerrada.
