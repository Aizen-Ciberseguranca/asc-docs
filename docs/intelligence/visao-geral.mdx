# Intelligence

O **Intelligence** é o módulo do Aizen Security Center dedicado ao acompanhamento de testes de segurança, exposição e vulnerabilidades.

O módulo centraliza informações sobre o escopo analisado, execuções realizadas, vulnerabilidades identificadas e resultados dos testes.

## Principais recursos

O Intelligence é organizado nas seguintes áreas:

### Dashboard

O **Dashboard** apresenta uma visão consolidada dos resultados do projeto.

Nele é possível acompanhar informações como:

- duração da execução;
- targets descobertos;
- vulnerabilidades identificadas;
- vulnerabilidades críticas;
- evolução da execução;
- severidade dos resultados;
- vulnerabilidades por target.

Também é possível consultar execuções anteriores do projeto.

### Execuções

A área **Execuções** apresenta o histórico das execuções realizadas.

Ela permite consultar informações como:

- status;
- origem da execução;
- pipeline utilizado;
- data de solicitação;
- início e término;
- duração;
- quantidade de achados.

### Agendamentos

A área **Agendamentos** permite configurar execuções recorrentes.

Dependendo das permissões do usuário, é possível criar agendamentos:

- diários;
- semanais;
- mensais.

Também é possível consultar, editar, ativar, desativar ou excluir agendamentos existentes.

### Escopo

A área **Escopo** apresenta os targets associados ao projeto.

Os targets podem incluir:

- domínios;
- hosts ou endereços IP;
- URLs.

A plataforma também diferencia targets definidos inicialmente daqueles identificados durante os testes.

### Vulnerabilidades

A área **Vulnerabilidades** centraliza os achados de segurança identificados.

É possível consultar:

- severidade;
- status;
- target afetado;
- descrição;
- recomendação;
- referências;
- primeira detecção;
- última detecção.

A interface oferece filtros e diferentes formas de agrupamento para facilitar a análise dos resultados.

### Relatórios e exportação

Os resultados do Intelligence podem ser exportados em diferentes formatos.

Dependendo do recurso utilizado, estão disponíveis formatos como:

- JSON;
- HTML;
- PDF;
- Word.

## Permissões

As funcionalidades disponíveis no Intelligence dependem do perfil do usuário.

Usuários de clientes possuem acesso aos resultados e às informações liberadas para seus projetos.

Algumas ações operacionais, como iniciar execuções, criar agendamentos ou alterar determinados elementos do escopo, são restritas aos perfis autorizados.

:::info
Se uma funcionalidade descrita nesta documentação não estiver disponível para sua conta, verifique as permissões associadas ao seu usuário e ao projeto selecionado.
:::
