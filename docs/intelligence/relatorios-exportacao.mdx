# Relatórios e exportação

O **Intelligence** permite exportar informações e resultados das análises realizadas no projeto.

Os formatos disponíveis podem variar de acordo com o tipo de informação ou relatório selecionado.

## Exportar resultados

Utilize as opções de exportação disponíveis na interface para gerar arquivos contendo os resultados do projeto.

Dependendo do recurso utilizado, podem estar disponíveis formatos como:

- **JSON**
- **HTML**
- **PDF**
- **Word**

## JSON

O formato **JSON** disponibiliza os dados em uma estrutura adequada para processamento automatizado, integrações ou análises adicionais.

Esse formato é indicado quando os resultados precisam ser consumidos por outras aplicações ou ferramentas.

## HTML

O formato **HTML** permite visualizar os resultados em um documento estruturado compatível com navegadores.

## PDF

O formato **PDF** gera um documento adequado para compartilhamento e consulta dos resultados.

Por manter uma estrutura de apresentação consistente, pode ser utilizado para distribuição dos resultados sem necessidade de edição posterior.

## Word

Quando disponível, o formato **Word** permite gerar um documento editável com os resultados exportados.

Esse formato pode ser utilizado quando for necessário complementar ou adaptar o conteúdo antes de seu compartilhamento.

## Conteúdo dos relatórios

O conteúdo apresentado depende do relatório ou recurso utilizado para realizar a exportação.

Os documentos podem incluir informações relacionadas a:

- projeto;
- execução;
- escopo analisado;
- targets;
- vulnerabilidades identificadas;
- severidade dos achados;
- detalhes técnicos;
- recomendações.

:::note
O conteúdo e os formatos disponíveis podem variar de acordo com o tipo de exportação e com as funcionalidades habilitadas para o projeto.
:::

## Compartilhamento dos resultados

Antes de compartilhar um relatório, verifique se o destinatário está autorizado a acessar as informações do projeto.

Os relatórios podem conter informações técnicas sobre vulnerabilidades, ativos e exposição do ambiente analisado.

:::warning
Trate os relatórios de segurança como informações sensíveis. O compartilhamento deve seguir as políticas de segurança e classificação da informação da organização.
:::

## Resultados atualizados

Os relatórios refletem os dados disponíveis no momento em que a exportação é realizada.

Caso novas execuções sejam realizadas ou os resultados sejam atualizados posteriormente, gere uma nova exportação para obter as informações mais recentes.
