# Dashboard

O **Dashboard** apresenta uma visão consolidada dos resultados das execuções realizadas no projeto selecionado.

Por meio dele, é possível acompanhar rapidamente o andamento dos testes e os principais indicadores de segurança identificados pelo Intelligence.

## Selecionar uma execução

Os dados apresentados no Dashboard estão associados a uma execução.

Utilize o seletor disponível na página para consultar a execução desejada.

Por padrão, o Dashboard pode apresentar a execução mais recente do projeto.

Ao selecionar outra execução, os indicadores e gráficos são atualizados de acordo com os resultados correspondentes.

## Indicadores principais

O Dashboard apresenta cards com os principais indicadores da execução.

### Duração

Apresenta o tempo total da execução selecionada.

### Targets descobertos

Apresenta a quantidade de targets identificados durante a execução.

Os targets descobertos podem complementar o escopo inicialmente definido para o projeto.

### Vulnerabilidades

Apresenta a quantidade total de vulnerabilidades identificadas na execução.

### Vulnerabilidades críticas

Apresenta a quantidade de vulnerabilidades classificadas com severidade **Crítica**.

Esse indicador permite identificar rapidamente a existência de achados que exigem maior prioridade de análise e tratamento.

## Evolução da execução

O gráfico **Evolução da execução** apresenta a progressão dos testes ao longo do tempo.

Ele permite acompanhar visualmente o avanço da execução e a evolução das etapas realizadas.

## Vulnerabilidades por severidade

O Dashboard apresenta a distribuição das vulnerabilidades de acordo com sua severidade.

As classificações utilizadas são:

- **Crítica**
- **Alta**
- **Média**
- **Baixa**
- **Informativa**

Essa visualização facilita a identificação da concentração de vulnerabilidades por nível de criticidade.

## Vulnerabilidades por target

A seção **Vulnerabilidades por target** apresenta a distribuição dos achados entre os targets analisados.

Essa visualização permite identificar quais ativos concentram maior quantidade de vulnerabilidades dentro da execução selecionada.

## Histórico de execuções

Além da execução atual, o Dashboard permite consultar execuções anteriores do projeto.

Utilize essa funcionalidade para comparar resultados e acompanhar diferentes ciclos de testes realizados sobre o mesmo projeto.

:::note
Os dados apresentados no Dashboard dependem da execução selecionada e dos resultados disponíveis para o projeto.
:::

## Atualização dos resultados

Durante uma execução em andamento, os dados podem ser atualizados conforme novas etapas são concluídas e novos resultados são processados.

Ao término da execução, o Dashboard apresenta a consolidação dos resultados coletados.
